# Інна Волос — нейропрактик

Сайт: https://svip-web.github.io/inna-volos/

Адаптивний статичний лендинг: HTML, CSS і JavaScript без сторонніх runtime-бібліотек. Оптимізовані WebP, локальні WOFF2, легка одноразова поява блоків при прокрутці й підтримка `prefers-reduced-motion`.

## Джерела та збірка

- `sites/inna-volos/` — редаговані джерела та потрібні сайту активи.
- `public/inna-volos/` — дзеркало для публікації.
- `scripts/inna-build.mjs` — об’єднання стилів і скриптів, версії за хешем, Brotli/gzip.
- `.github/workflows/pages.yml` — перевірка і публікація GitHub Pages після push у `codex/launch`.

Потрібен Node.js 22 або новіший; npm-залежностей немає.

```sh
npm run build
npm run check
npm test
```

Редагуйте окремі CSS/JS, не згенеровані `site.min.*`. Після зміни HTML, CSS/JS-джерел чи активів віддзеркальте змінені файли із `sites/inna-volos/` у `public/inna-volos/`, потім запустіть збірку і перевірки. Каталог `public/inna-volos/` публікується як корінь сайту; всі посилання на ресурси відносні, тому працюють і в підкаталозі GitHub Pages.

У репозиторій включені тільки файли цього сайту. Локальні заявки, секрети, інші проєкти, оригінальні важкі фото та чернетки не публікуються. Згенеровані `.br`/`.gz` збережені для хостингів, які підтримують готові стиснені файли; конфігурацією кешування та стиснення GitHub Pages керує GitHub.

## Контент і ліцензії

Фото Інни та затверджені візуальні композиції збережені з робочого макета. Попередні демонстраційні тексти відгуків залишені як у затвердженому макеті; перед комерційним використанням їх потрібно замінити підтвердженими реальними відгуками.

Ліцензії локальних шрифтів: `sites/inna-volos/assets/fonts/OFL.txt`. Публічність репозиторію не надає автоматичної ліцензії на використання фотографій, текстів чи бренду.
